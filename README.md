# Controle de Gastos CAD — V2.4

PWA para duas pessoas, com funcionamento offline.

- IndexedDB
- Entradas e despesas
- Despesas individuais e compartilhadas
- Divisão 50/50 ou personalizada
- Saldo compartilhado descontado de cada pessoa conforme sua parte
- Editar/excluir
- Resumo por pessoa
- Sem cálculo de dívida/acerto entre as pessoas
- Nomes das pessoas atualizados automaticamente nos campos de quem pagou/recebeu
- Backup/restauração
- Service Worker offline
